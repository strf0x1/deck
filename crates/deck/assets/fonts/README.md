# Bundled fonts

These files load into Deck only. They do not install system fonts.

- Obel Mono and Obel Mono Masked 1.003: https://typographic.systems/obel-mono. Original regular TTFs from `ObelMono-1.003-ttf.zip` and `ObelMonoMasked-1.003-ttf.zip`. License and copyright: `OFL-ObelMono.txt`, `AUTHORS-ObelMono.txt`.
- JetBrains Mono 2.304: https://github.com/JetBrains/JetBrainsMono/tree/v2.304. Original `fonts/variable/JetBrainsMono[wght].ttf`. License and copyright: `OFL-JetBrainsMono.txt`.
