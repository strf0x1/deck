# Bundled icons

Single-colour icons, drawn as SVG. Deck tints them, so each file is one opaque path on a 24×24 grid and carries no colour of its own (`fill="#ffffff"` only sets alpha).

- Material Symbols (Google), Outlined style: https://fonts.google.com/icons — License and copyright: `Apache-2.0.txt`.
- `github.svg`: Material Design Icons 7.x (Pictogrammers), https://pictogrammers.com/library/mdi/ — also `Apache-2.0.txt`.

Fetched from the Iconify API (`https://api.iconify.design/<collection>/<name>.svg`) and then modified: the root `width`/`height` set to `24` and `fill="currentColor"` replaced by `fill="#ffffff"`, so the shape is opaque regardless of the host's text colour. Path data unchanged.
