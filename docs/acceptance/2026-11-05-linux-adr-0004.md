## ADR review

The current ADR records the model/web gateways, bounded approvals, status
feedback, usage budgets, credential broker and store, and active web/model
grant revocation as landed. The GitHub operation gateway is covered by ADR
0007. Deferred SSH-agent signing is distinct from the SSH transport tested
here: the guest receives no user private key or SSH-agent identity.

The ADR's early evidence paragraphs are historical slice reports, not a
statement that later slices are absent. The explicitly outstanding Linux OS
store and public-network checks motivated this run. This pass does not
claim gateway confinement, private registry support, or a complete security
acceptance of every bypass scenario.

## Public TLS and SSH

Before correction, curl receives a 200 CONNECT reply then fails with OpenSSL
`https proxy request` (exit 35). The gateway echoes the CONNECT head back into
the tunnel. Local correction consumes that head and sends only the response
followed by destination bytes. The real-binary tunnel test now asserts the
exact greeting after the status, catching the previously tolerated corruption.

With the correction, guest curl verifies public GitHub TLS and receives the
HTTPS response through the real relay. It also works after guest `/etc/hosts`
assigns github.com to loopback: the gateway resolves on the host.

SSH through `socat ... PROXY:127.0.0.1:%h:%p,proxyport=8082` initially returns
Forbidden for `ssh.github.com:443`. A task-scoped approval enables a real SSH
handshake and host-key handling; authentication ends with `Permission denied
(publickey)` as expected without an identity. Port 22 remains Forbidden. No
repository operations or authenticated SSH commands were performed.
